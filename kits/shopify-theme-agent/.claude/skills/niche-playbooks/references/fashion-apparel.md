# Fashion & apparel (clothing, shoes, bags)

**Buyer:** style-driven, compares a lot, #1 fear is **wrong size** (and return hassle).

## Product page must-haves
1. Size guide with **body measurements AND garment measurements** + "model is 5'7", wears S"
2. Fit note: runs small / true to size / relaxed; stretch level
3. Many photos: front, back, side, detail, on 2+ body types, flat lay; short try-on video
4. Fabric & care tab (composition %, weight, washing)
5. Colour swatches with native Shopify swatches (set colours in Admin)
6. Easy exchange policy stated near Add to cart ("Free size exchange within 30 days" only if true)

## Offers that work
- Buy 2 save 10 %, buy 3 save 15–20 % (mix sizes/colours → bundle picker per-unit variants)
- Free shipping threshold slightly above AOV
- Matching sets / "complete the look"

## brand.json hints
Mood "Soft luxury" (premium) or "Bold & energetic" (streetwear/activewear) · radius `sharp` or `soft` ·
`size_guide` required · tabs: Size & fit / Fabric & care / Shipping / Exchanges.

## Red flags
- Brand logos, trademarked prints, characters (Disney, sports teams) → counterfeit, instant bans
- "100% cotton", "organic", "vegan leather" must be true (FTC textile rules; composition labels required in US/EU)
- Fake "celebrity wears" claims
- Sizing charts copied from the competitor → use the supplier's real measurements
