# Method for any other niche

Answer these 8 questions (from the competitor teardown, the supplier listing, 1-star
reviews of similar products on Amazon/AliExpress, and Reddit threads). Save the result
as `references/<niche>.md` using the same headings as the other playbooks.

1. **Buyer:** who buys, for whom (self/gift), what triggers the purchase?
2. **Top 3 fears** before buying (read 1–3 star reviews of similar products: sizing,
   quality, "doesn't work", late delivery, hard to use…)
3. **Proof that removes each fear:** which photo, video, spec, guarantee or FAQ answers it?
4. **Product-page must-haves:** map each proof to a section (tabs, size guide, how it
   works, comparison, stories, FAQ)
5. **Offer:** would people buy 2–3? For whom (gift, family, spare, refills)? → bundle labels
6. **Mood and look:** pick a mood from `shopify-theme-kit/references/design-system.md`
   that differs from the main competitor
7. **Red flags:** regulated words in this niche (health, safety, kids, electrical,
   materials, certifications, trademarks). Search "<niche> FTC claims", "<niche> Meta ads
   policy", "<product> certification required US/EU"
8. **FAQ topics:** 6–12 real questions (from reviews, Q&A sections, Reddit)

Then fill brand.json hints: mood, radius, 3 trust icons, tabs, FAQ.
