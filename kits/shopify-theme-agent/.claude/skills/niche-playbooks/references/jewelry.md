# Jewelry, watches & accessories

**Buyer:** gift buyers (partners, mothers, friends) and self-purchase; fears tarnish,
green skin, cheap look, wrong ring size, late delivery for a date.

## Product page must-haves
1. Macro photos + **on-body photos** for scale; video with natural light (sparkle)
2. Materials tab: base metal, plating type and thickness, stone type; hypoallergenic only if tested
3. Size guide (ring sizes, chain lengths on a neck diagram)
4. Care instructions (avoid water/perfume for plated items)
5. Gift options: gift box, message card (only if really available)
6. Delivery estimate prominent (gift deadlines)

## Offers that work
- "Buy 2, save 15 %" (gift + self), matching sets (necklace + earrings)
- Gift-ready packaging included
- Personalisation (engraving) → see personalized-gifts.md

## brand.json hints
Mood "Soft luxury" · radius `sharp` · fonts serif heading (cormorant_n6) · trust icons
`star`, `truck`, `heart` · tabs: Materials / Size guide / Care / Shipping / Returns.

## Red flags
- "Solid gold", "sterling silver 925", "real diamond", "moissanite" → must be exact (FTC Jewelry Guides)
- "Gold" for plated items must say "gold plated" / "gold vermeil" correctly
- "Hypoallergenic", "nickel-free", "waterproof", "won't tarnish" → only with proof
- Brand-lookalike designs (Cartier, Van Cleef, Pandora) → IP takedowns
