# Niche playbooks

1. Identify the niche from the product and the brand brief. Open the matching file in
   `references/`. Several can apply (e.g. a personalised pet portrait → `pets.md` + `personalized-gifts.md`).
2. No matching file → follow `references/_any-niche.md` to derive one, and save it as
   `references/<niche>.md` so the next store in that niche starts faster.
3. Use the playbook in three places:
   - **Plan** (teardown/plan.md): which competitor patterns are table stakes in the niche,
     which weaknesses matter most
   - **brand.json**: mood/palette, bundle labels, trust icons, tabs, FAQ topics
   - **Compliance**: every claim on the page and in ads checked against the "Red flags" list

Universal rules (all niches): real reviews only, real compare-at prices only, no fake
countdowns or stock counters, no competitor names in copy, no competitor photos,
claims only with proof, delivery times = supplier time + 2–3 days buffer.
