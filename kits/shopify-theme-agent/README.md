# AI Agent Thiết Kế Theme Shopify

Mở **HUONG-DAN.html** (bấm đúp) để xem hướng dẫn cài đặt và sử dụng chi tiết.

Tóm tắt:
1. Giải nén vào thư mục không dấu, ngoài OneDrive (ví dụ `C:\Shopify\ten-thuong-hieu`).
2. Cài phần mềm: Windows `powershell -ExecutionPolicy Bypass -File setup\setup-windows.ps1`,
   macOS `bash setup/setup-mac.sh`.
3. Mở cửa sổ lệnh mới trong thư mục, gõ `claude`, đăng nhập, rồi gõ `/bat-dau`.
