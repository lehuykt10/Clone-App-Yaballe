Ad Library Scout

Tìm store đang có sản phẩm winning trên Meta Ad Library: gom quảng cáo theo store, chấm điểm 0–100 dựa trên số ads đang chạy, số ngày chạy, creative mới và reach, rồi ước tính chi tiêu và số đơn.

Tạo câu truy vấn

Điền từ khóa, bấm Copy rồi dán vào Graph API Explorer (xem hướng dẫn bước 3 bên dưới).

Gõ EU ở ô quốc gia để lấy cả 27 nước EU. API chỉ trả quảng cáo thương mại chạy ở EU.

Nạp dữ liệu

Giả định ước tính

Đây là ước tính, không phải số thật. Meta không công bố chi tiêu của quảng cáo thương mại. Chi tiêu = reach EU × tần suất × CPM; khi không có reach (CSV nhập tay) thì = số ads × số ngày × $/ad/ngày. Số đơn = chi tiêu × ROAS ÷ AOV. Dùng các con số này để so sánh các store với nhau.

Hướng dẫn từng bước

Xác minh danh tính để dùng Ad Library API (một lần)

  1. Mở facebook.com/ID, đăng nhập Facebook cá nhân.
  2. Làm theo hướng dẫn xác minh (giấy tờ tùy thân, xác nhận vị trí). Thường mất từ vài phút đến 1–2 ngày.

Tạo app trên Meta for Developers (một lần)

  1. Vào developers.facebook.com/apps → Create App.
  2. Chọn mục đích Other → loại app Business → đặt tên, ví dụ "Zenligo Research" → Create.
  3. Không cần thêm sản phẩm nào cho app. Chỉ cần app tồn tại để lấy token.

Lấy dữ liệu bằng Graph API Explorer (không cần cài đặt)

  1. Mở Graph API Explorer.
  2. Ở ô Meta App, chọn app vừa tạo → bấm Generate Access Token → đồng ý.
  3. Ở phần Tạo câu truy vấn trên trang này, nhập từ khóa → bấm Copy truy vấn cho Explorer.
  4. Trong Explorer, xóa ô đường dẫn sau graph.facebook.com/vXX.X/, dán truy vấn vào → bấm Submit.
  5. Kết quả JSON hiện ở khung bên phải. Bấm vào khung → Ctrl+A → Ctrl+C.
  6. Nếu cuối kết quả có "paging": { "next": ... }, nghĩa là còn trang sau. Copy đường dẫn next, mở ở tab mới để lấy trang tiếp theo.

Token từ Explorer hết hạn sau khoảng 1–2 giờ. Khi gặp lỗi "Session has expired", bấm Generate Access Token lại. Không gửi token cho người khác.

Dán dữ liệu vào trang này

  1. Dán JSON vào ô Nạp dữ liệu → bấm Thêm vào dữ liệu. Lặp lại với từng trang; quảng cáo trùng sẽ tự bị loại.
  2. Có thể chạy nhiều từ khóa (ví dụ "migraine cap", "headache hat", "ice head wrap"), rồi dán tất cả vào để so sánh chung.
  3. Bấm Nạp dữ liệu mẫu nếu chỉ muốn xem tool hoạt động thế nào.

Chỉnh giả định và đọc kết quả

  • AOV: xem giá bán trên store đối thủ (giá gói phổ biến nhất).
  • CPM: EU khoảng $6–12; nếu bạn đang ước tính cho Mỹ, dùng $12–25.
  • Tối thiểu ads đang chạy: tăng lên 5–10 để chỉ xem store đang chạy mạnh.
  • Bấm Xem thêm ở mỗi dòng để đọc nội dung quảng cáo và mở link từng quảng cáo.
  • Copy CSV rồi dán vào Google Sheets để lưu và theo dõi theo tuần.

Thêm quảng cáo ở Mỹ (nhập tay)

  1. Mở Ad Library → Country: United States → Ad category: All ads → tìm theo từ khóa hoặc tên store.
  2. Ghi mỗi quảng cáo một dòng theo mẫu CSV dưới đây, rồi dán vào ô Nạp dữ liệu.
page_name,domain,start_date,end_date,ad_url,text,countries Store X,storex.com,2026-10-05,,https://www.facebook.com/ads/library/?id=...,"Câu đầu của quảng cáo",US

start_date = ngày "Started running on…" · để trống end_date nếu quảng cáo còn chạy. Không dùng bot cào website Ad Library: vi phạm điều khoản Meta.

Lấy số lượng lớn bằng dòng lệnh (tùy chọn)

Khi cần hàng nghìn quảng cáo, dùng bản Python trong repo: thư mục tools/ads_library_scout/. Nó tự lật trang, tự gộp nhiều từ khóa, rồi xuất file raw.json; dán hoặc tải file đó lên trang này.

export META_ACCESS_TOKEN="..." python3 tools/ads_library_scout/scout.py fetch --terms "migraine cap" "headache hat" --countries EU --out raw.json
